# Rust String Encryptor

Графическое приложение для шифрования и дешифрования текста по паролю (AES-256-GCM + Argon2id).

## Технические детали

- **Шифрование**: AES-256-GCM (аутентифицированное шифрование)
- **Деривация ключа**: Argon2id (защита от брутфорса)
- **Формат вывода**: Base64 с заголовками (`-----BEGIN RUST-ENC V2-----`), строки по 64 символа
- **Параметры Argon2** (память, итерации, потоки) хранятся в самом сообщении и защищены как AAD — их можно повышать, не ломая старые шифротексты
- **Обратная совместимость**: сообщения формата V1 по-прежнему расшифровываются
- **Очистка памяти**: ключи через `Zeroizing`, пароли затираются в `Drop`

## Скачать

Готовый `.exe` для Windows — на странице [Releases](https://github.com/FaustVik/rust-string-encryptor/releases/latest).
Рядом лежит файл `.sha256` для проверки целостности.

## Сборка из исходников

```bash
cargo build --release
```

## Использование

```bash
# Запуск GUI
cargo run --release
```

Приложение имеет две панели:
- **Encrypt** — ввод текста, пароля и его повтора, шифрование
- **Decrypt** — вставка зашифрованного блока и пароля, дешифрование

Деривация ключа выполняется в фоновом потоке — окно не зависает.
Результат можно скопировать в буфер обмена; расшифрованный текст автоматически
удаляется из буфера через 30 секунд (и при закрытии приложения).

## Разработка

```bash
cargo test
cargo clippy --all-targets -- -D warnings
cargo fmt --check
```

Те же проверки и release-сборка запускаются в GitHub Actions (`.github/workflows/ci.yml`).
Минимальная версия Rust — 1.85.

### Релиз

1. Поднять `version` в `Cargo.toml` и закоммитить в `master`.
2. Создать и отправить тег с той же версией:

```bash
git tag v0.2.0
git push origin v0.2.0
```

Workflow `release.yml` проверит, что тег совпадает с версией в `Cargo.toml`,
прогонит тесты, соберёт `.exe` и опубликует GitHub Release с автоописанием.

## Безопасность

- Ключи шифрования обёрнуты в `Zeroizing` — автоматическое затирание при выходе из области видимости, включая паники
- Пароли и открытый текст затираются при закрытии окна (`Drop`); расшифрованные байты — сразу после использования
- Параметры Argon2 из сообщения ограничены сверху (≤ 1 GiB памяти), чтобы поддельное сообщение не могло «повесить» приложение
- Повтор пароля при шифровании и предупреждение о коротком пароле
- Криптографически стойкий CSPRNG (OsRng)
- Уникальные соль и nonce для каждого шифрования
